# Flight Commander 4.2.2

Flight Commander 4.2.2 is a Configurator-only release. It retains the verified
Firmware 4.2.0 images for both supported flight-controller targets without
rebuilding or modifying either image.

## Configurator

- Keep RTCM correction delivery live over both MSP and MAVLink when routine
  telemetry, mission traffic, or a slow radio link creates congestion.
- Prioritize flight-control and heartbeat MAVLink messages first, RTCM
  corrections second, and routine traffic afterward.
- Coalesce queued corrections to the newest complete frame of each RTCM
  message type so a faster caster cannot create an ever-growing stale backlog.
- Admit fresh RTCM writes to a saturated serial transmit buffer by replacing
  unsent stale corrections or displacing lower-priority traffic.
- Bound stalled or unacknowledged correction writes and abandon the incomplete
  frame before the firmware fragment-assembly window expires, allowing the
  stream to recover automatically with current data.
- Preserve complete RTCM frame and fragment ordering during normal delivery.
- Show aircraft GPS state consistently as **No Fix**, **3D Fix**,
  **RTK Float**, or **RTK Fix** on the live HUD and GPS telemetry tile over
  either MSP or MAVLink.

## Unchanged firmware included

- Flight Commander Firmware 4.2.0 for MICOAIR743.
- Flight Commander Firmware 4.2.0 for CUBEORANGEPLUS.
- Exact Firmware 4.2.0 source archive corresponding to those binaries.
