# Flight Commander 4.1.9

Flight Commander 4.1.9 is a coordinated Configurator and Firmware release for
MICOAIR743 and CubePilot Cube Orange+. It restores discovery and calibration of
the compass built into Holybro/AP_Periph-compatible DroneCAN GPS modules.

## DroneCAN compass compatibility

- Accepts legacy `uavcan.equipment.ahrs.MagneticFieldStrength` message ID 1001
  in addition to `MagneticFieldStrength2` message ID 1002.
- Normalizes both message formats into the same per-node magnetic-source path.
- Marks the transmitting CAN node as compass-capable so it appears in the
  Calibration source selector and becomes available to heading fusion after
  its own orientation learning and magnetic-field calibration are complete.
- Applies the shared firmware correction to both official targets.

No firmware update is required on a Holybro H-RTK F9P rover that is already
healthy and transmitting DroneCAN GPS and compass data.

## Release verification

Both images are rebuilt with the pinned Arm GNU 13.2.1 toolchain and warnings
as errors. Publication verifies their embedded `FCFW` 4.1.9 identity, target
string, Intel HEX checksum, vector table, start address, byte range, SHA-256,
and exact source identity. The Cube check rejects any image byte below
`0x08020000`.

These automated checks do not substitute for propeller-off hardware acceptance.
After flashing, confirm the DroneCAN GPS node reports both GNSS and compass
capabilities, complete learned orientation and field calibration for that
source, save and reboot, and verify stable heading before flight.

`Flight-Commander-v4.1.9.zip` contains exactly:

standalone GitHub release assets for Configurator's online flasher:

- `Flight-Commander-Firmware-4.1.9-MICOAIR743.hex`

Remove propellers for all setup, calibration, flashing recovery, output tests,
and initial bench acceptance.
