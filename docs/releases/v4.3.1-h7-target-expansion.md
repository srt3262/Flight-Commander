## Additive H7 target expansion

Flight Commander 4.3.1 now provides standalone online-flasher assets for every
STM32H743 target variant supported by official INAV 9.1.0. This adds 48 firmware
assets to the two controller assets that were already published.

The existing `MICOAIR743`, `CUBEORANGEPLUS`, and complete-release ZIP assets
were not replaced. Before publishing the additions, the build reproduces both
published controller HEX files and requires their original SHA-256 values. The
protected MICOAIR743 digest is
`1fcb891cd7bcee51e86c6dcf0afcc58bc9228584cc3105406e33d00d9ebb7921`.

Every added image is built with Arm GNU 13.2.1 and warnings as errors, then
checked for valid Intel HEX records, its exact embedded target, the Flight
Commander 4.3.1 identity, the target-aware capability mask, vector table, start
address, and protected flash range. Boards without an official CAN pin mapping
advertise the non-DroneCAN capability mask; mapped boards receive the full
DroneCAN feature set.

Compilation and structural verification do not replace propeller-off hardware
bench testing on the exact flight-controller revision.
