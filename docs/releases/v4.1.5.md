# Flight Commander 4.1.5

Flight Commander 4.1.5 corrects the remaining Ground Control command-profile
collision defect in the official 4.1.4 release.

## Ground Control correction

- Removes the obsolete **Multiple INAV controller profiles use MAVLink system
  ID** warning and the unreachable instruction to select a controller profile.
- Automatically migrates duplicate profile records left by Configurator 4.1.4
  and earlier. The most recent wired Flight Commander capture becomes the
  command mapping for that MAVLink system ID.
- Replaces an existing command profile whenever the same `mavlink_sysid` is
  captured again, so firmware flashes, controller renames, or identity-field
  changes cannot accumulate another blocking collision.
- Keeps the checks that commands actually require: a live MAVLink link, a known
  target, current receiver and AUX mappings, and a confirmable resulting state.
  Firmware identity metadata remains diagnostic and does not authorize or block
  the controls.

Operators with more than one aircraft should give each controller a unique
`mavlink_sysid`; two aircraft sharing one system ID cannot be targeted
independently.

## Firmware scope

The MICOAIR743 firmware receives the matching 4.1.5 release identity. Its
reviewed flight-control behavior and capability mask are unchanged from 4.1.4.
