# Flight Commander 4.2.4

Flight Commander 4.2.4 is a Configurator-only CubePilot flashing release. It
retains the verified Firmware 4.2.0 images for both supported
flight-controller targets without rebuilding or modifying either image.

## Configurator

- Flash CubePilot Cube Orange+ through its protected Cube/Pixhawk serial
  bootloader instead of requiring an STM32 ROM DFU button that the Cube does
  not expose.
- For the first installation from ArduPilot, send the standard MAVLink
  preflight reboot command with the bootloader selector and watch for the
  vendor bootloader USB port.
- For later updates from Flight Commander, identify `CUBEORANGEPLUS` over MSP,
  request the existing normal reset, and reacquire the same vendor bootloader
  before the application starts.
- If neither running application answers, keep a 20-second watcher active so
  an operator can unplug and reconnect USB to expose the bootloader.
- Require bootloader board ID `1063`, reject HEX data outside the protected
  application range, and forbid full-chip erase before programming begins.
- Program the application at `0x08020000`, verify the complete bootloader CRC,
  and reboot only after successful verification.
- Show an actionable status when Flash is disabled or a Cube serial port has
  not been selected, replacing the prior apparently unresponsive click.

## Unchanged firmware included

- Flight Commander Firmware 4.2.0 for MICOAIR743.
- Flight Commander Firmware 4.2.0 for CUBEORANGEPLUS.
- Exact Firmware 4.2.0 source archive corresponding to those binaries.
