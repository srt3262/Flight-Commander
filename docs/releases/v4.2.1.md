# Flight Commander 4.2.1

Flight Commander 4.2.1 is a Configurator-only release. It retains the verified
Firmware 4.2.0 images for both supported flight-controller targets without
rebuilding or modifying either image.

## Configurator

- Rank NTRIP mountpoints nearest-first using the connected USB base position.
- Fall back to the aircraft rover position when no valid USB base is connected.
- Show the calculated distance for every mountpoint that publishes coordinates.
- Label mountpoints as compatible, limited, unknown, or incompatible with the
  u-blox F9P based on their published RTCM format, messages, carrier mode, and
  constellations.
- Keep streams without published coordinates available at the bottom of the
  list with `distance unavailable` shown explicitly.

## Unchanged firmware included

- Flight Commander Firmware 4.2.0 for MICOAIR743.
- Flight Commander Firmware 4.2.0 for CUBEORANGEPLUS.
- Exact Firmware 4.2.0 source archive corresponding to those binaries.
