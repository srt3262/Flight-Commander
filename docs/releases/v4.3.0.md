# Flight Commander 4.3.0

Flight Commander 4.3.0 is a coordinated Configurator and Firmware release for
MICOAIR743 and CubePilot Cube Orange+. The Configurator and both official
firmware targets share the exact 4.3.0 version.

## Save-and-reboot reconnection

- Preserve the exact MSP COM port, protocol, and baud selected before reboot.
- After the normal reboot settle delay, wait up to 30 seconds for that exact
  Windows COM port to reappear instead of consuming all open attempts while it
  is absent.
- Ignore unrelated COM devices that enumerate during the wait.
- If Windows lists the correct port before its driver is ready to open, retry
  automatically at a bounded interval.
- Keep the existing three-attempt limit and finish in a clean disconnected
  state with an actionable message if recovery cannot complete.

## CubePilot carrier-board port labels

The Ports tab now leads with the connector name printed on Cube carrier-board
documentation while retaining the STM32 UART in parentheses:

- `TELEM1 (UART2)`
- `TELEM2 (UART3)`
- `GPS1 (UART4)`
- `CONS / ADS-B (UART7)`
- `GPS2 (UART8)`

These display labels are enabled only for target `CUBEORANGEPLUS` or board
identifier `COPL`; the saved serial identifiers and target pin map do not
change. MICOAIR743 retains its normal UART labels.

## Coordinated firmware identity

Both official images are rebuilt with pinned Arm GNU 13.2.1 and warnings as
errors. Publication verifies their embedded `FCFW` 4.3.0 identity and
`0x0001ffff` capability mask, exact target, Intel HEX structure, protected
address range, source identity, byte count, and SHA-256.

## Cube Orange+ corrected startup baseline

- Retain the Cube bootloader handoff that was bench-validated in Firmware
  4.2.9: normalize MSP, PSP, and CONTROL before C startup, preserve the
  interrupt lock through HAL/NVIC initialization, and initialize the pinned
  ArduPilot 4.7.0 Cube power, GPIO, and clock state.
- Enable the USB CDC polling timer clock before configuring TIM7 and advertise
  the distinct `Flight Commander CubeOrange+` USB identity.
- Keep the corrected 4.3.0 primary and secondary IMU transforms. The release
  source verifier now treats the startup handoff and both transforms as
  required Cube Orange+ contracts.

## Canonical bundle

`Flight-Commander-v4.3.0.zip` contains exactly:

- `FC-Windows-v4.3.0.zip`
