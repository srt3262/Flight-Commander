# Flight Commander 4.1.7

Flight Commander 4.1.7 makes the Ground Control primary mode indication
identical over MSP and MAVLink and removes the remaining INAV branding from
generated backup and restore files.

## Primary mode indication

- Displays only `ACRO`, `ANGLE`, `ANGLE/ALT HLD`, `GPS POS HLD`, `RTH`, or
  `MISSION` in the Ground Control mode card and live HUD.
- Uses strict priority: RTH, mission, GPS position hold, angle plus altitude
  hold, angle, then acro.
- Ignores MC braking, air mode, GCS NAV, heading hold, and every other secondary
  box when choosing the primary display mode.
- Reports live configured switch selections over MSP and MAVLink even before a
  missing GPS or another navigation prerequisite lets that mode engage.

## Flight Commander backups

- Generates `flight_commander_backup_...` filenames instead of
  `inav_backup_...` filenames.
- Writes Flight Commander headers for normal and automatic pre-flash backups.
- Uses a `flight-commander-backups` default folder and labels save and restore
  dialogs as Flight Commander Backup/Restore.
- Non-destructively copies prior CLI/TXT backups into the new default folder,
  and continues to accept their legacy comment headers and commands.
