# Flight Commander 4.2.3

Flight Commander 4.2.3 is a Configurator-only reliability release. It retains
the verified Firmware 4.2.0 images for both supported flight-controller targets
without rebuilding or modifying either image.

## Configurator

- Prevent a fast NTRIP caster from filling a slower telemetry radio's hidden
  transmit buffer by pacing complete RTCM frames over both MSP and MAVLink.
- Continue coalescing corrections while pacing so the newest complete frame of
  each RTCM message type replaces stale data before transmission begins.
- Replace the premature 400 ms transport deadline with a bounded 2.5 second
  native-write stall threshold that tolerates normal radio backpressure.
- Purge a genuinely stalled serial write and advance directly to the newest
  queued correction so RTCM forwarding recovers automatically.
- Hold a replacement write until the old purge completes, preventing fresh
  correction bytes from being discarded by a concurrent native purge.
- Preserve higher transport priority for flight-control and heartbeat MAVLink
  traffic while RTCM corrections remain ahead of routine telemetry traffic.

## Unchanged firmware included

- Flight Commander Firmware 4.2.0 for MICOAIR743.
- Flight Commander Firmware 4.2.0 for CUBEORANGEPLUS.
- Exact Firmware 4.2.0 source archive corresponding to those binaries.
