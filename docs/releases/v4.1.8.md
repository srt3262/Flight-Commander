# Flight Commander 4.1.8

Flight Commander 4.1.8 is a coordinated Configurator and Firmware release. It
adds the first official CubePilot Cube Orange+ target while retaining a rebuilt
MICOAIR743 image under the same 4.1.8 firmware identity.

## CubePilot Cube Orange+

- Adds the `CUBEORANGEPLUS` STM32H757 target with its 24 MHz clock and mandatory
  direct-SMPS power configuration.
- Preserves the Cube's 128 KiB vendor bootloader by placing the application
  vector table at `0x08020000`; the Configurator disables full-chip erase for
  this target.
- Supports the two isolated SPI4 ICM42688-P/ICM45686 positions, primary
  MS5611, microSD, CAN1, connector UARTs, external I2C compass, Power Brick 1,
  LED, and passive buzzer.
- Exposes exactly AUX1-AUX6 as direct FMU motor/servo outputs.
- Keeps USART6 reserved for the external STM32F100 IOMCU. MAIN1-MAIN8 and the
  physical RC input are not supported until Flight Commander implements the
  PX4IO protocol; use a bidirectional MAVLink receiver/control link.
- Requires an external I2C or DroneCAN compass because the Cube-mounted
  AK09916 path is not enabled in this release.

Read the [Cube Orange+ target guide](../CUBEORANGEPLUS.md) before flashing or
configuring outputs.

## Release verification

Both images are rebuilt with the pinned Arm GNU 13.2.1 toolchain and warnings
as errors. Publication verifies their embedded `FCFW` 4.1.8 identity, target
string, Intel HEX checksum, vector table, start address, byte range, SHA-256,
and exact source identity. The Cube check rejects any image byte below
`0x08020000`.

These automated checks do not substitute for propeller-off hardware acceptance.
Verify sensor axes, cold starts, power rails, GNSS, compass, CAN, microSD,
battery scaling, all six AUX outputs, MAVLink receiver loss, and failsafe on
the actual carrier board before flight.

## Canonical bundle

`Flight-Commander-v4.1.8.zip` contains exactly:

- `FC-Windows-v4.1.8.zip`
- `FC-Configurator-Source-v4.1.8.zip`
- `FC-Firmware-v4.1.8-MICOAIR743.hex`
- `FC-Firmware-v4.1.8-CUBEORANGEPLUS.hex`
- `FC-Firmware-Source-v4.1.8.zip`

The two firmware images are also published under their canonical long names as
standalone GitHub release assets for Configurator's online flasher:

- `Flight-Commander-Firmware-4.1.8-MICOAIR743.hex`
- `Flight-Commander-Firmware-4.1.8-CUBEORANGEPLUS.hex`

Remove propellers for all setup, calibration, flashing recovery, output tests,
and initial bench acceptance.
