# Flight Commander 4.1.6

Flight Commander 4.1.6 replaces the remaining cached AUX-profile Ground
Control path with coordinated native MAVLink commands in the Configurator and
MICOAIR743 firmware.

## Native Ground Control commands

- Removes the cached MSP command-profile store, per-command AUX-range lookup,
  sustained `RC_CHANNELS_OVERRIDE` transmission, and the obsolete disabled
  tooltip that required an AUX range for every command.
- Sends acknowledged native MAVLink commands for arm/disarm, navigation modes,
  mission start/resume/abort, return-to-launch, and landing.
- Supports fixed-wing launch through the existing firmware launch controller.
  Multirotor automatic takeoff remains unavailable until a dedicated takeoff
  controller is implemented and bench validated.
- Queues mission navigation until the normal firmware arming checks succeed,
  avoiding the existing navigation-mode-active arming blocker.

## GCS NAV authorization

- Requires the saved physical **GCS NAV** mode before any native flight command
  can be sent or accepted.
- Advertises live GCS NAV authorization in the vehicle heartbeat so Ground
  Control disables commands immediately when the switch is off.
- Rechecks the live authorization at click time in the Configurator and again
  inside firmware for command, mission-current, and reposition messages.
- Prevents Ground Control commands from enabling their own GCS NAV gate.
- Revokes GCS-owned mode and arm state when the physical GCS NAV mode is turned
  off, preserving direct pilot control as the authority boundary.
