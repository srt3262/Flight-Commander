# Flight Commander 4.2.0

Flight Commander 4.2.0 is a coordinated Configurator and Firmware release for
MICOAIR743 and CubePilot Cube Orange+. It adds a built-in USB-to-DroneCAN
maintenance adapter compatible with the LAWICEL/SLCAN protocol used by
DroneCAN GUI.

## USB DroneCAN maintenance bridge

- Enters only while the aircraft is disarmed and the DroneCAN bus is online at
  125, 250, 500, or 1000 kbit/s.
- Uses the USB serial port that requested entry and retains the already-active
  CAN bitrate. Standard SLCAN bitrate commands are acknowledged only when they
  match that live bitrate.
- Supports standard 11-bit and 29-bit CAN data/remote frames, optional SLCAN
  timestamps, adapter identity/status queries, bounded receive/transmit queues,
  and CAN bus-off recovery.
- Suspends Flight Commander's normal DroneCAN node, GPS/RTK, compass, RTCM, and
  AP_Periph service traffic while raw bridge ownership is active.
- Latches an arming blocker for the entire maintenance session. Rebooting the
  flight controller is the only exit path.
- Is compiled and verified for both MICOAIR743 and CUBEORANGEPLUS.

Configurator's **GPS** tab checks the live bus and arming state, shows the exact
bitrate to select in DroneCAN GUI, warns against interrupting the powered CAN
hub during a node firmware update, sends a single guarded MSP request, and then
disconnects its serial session so DroneCAN GUI can open the same COM port.

## Safe use

Remove propellers and keep the aircraft disarmed. With the Holybro powered CAN
hub and Holybro DroneCAN H-RTK F9P node powered, verify **Online · 1000 kbit/s**
in Configurator, enter the bridge, then select **SLCAN**, the same COM port, and
1000000 bit/s in DroneCAN GUI. Close DroneCAN GUI and reboot the flight
controller before returning to Configurator. Never interrupt power while a CAN
node firmware write is active.

## Release verification

Both images are rebuilt with pinned Arm GNU 13.2.1 and warnings as errors.
Publication verifies their embedded `FCFW` 4.2.0 identity and `0x0001ffff`
capability mask, target string, Intel HEX checksums, vector table, protected
address ranges, exact source identity, byte count, and SHA-256. Automated
structural checks do not replace propeller-off acceptance on the actual
aircraft and CAN hardware.
