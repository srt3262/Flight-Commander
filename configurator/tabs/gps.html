    DroneCAN GPS / RTK configuration

    Waiting for DroneCAN bus status…

    UART and DroneCAN receivers remain active together. Either can be the navigation primary, and both retain independent RTK Float/Fixed state and receive RTCM corrections. Battery-node assignments remain available in Ports.

    DroneCAN GUI maintenance bridge

    Temporarily expose this USB port as a standards-compatible LAWICEL/SLCAN adapter. Use it with DroneCAN GUI to inspect AP_Periph parameters or update node firmware.

    Checking whether bridge entry is safe…

    Maintenance mode blocks arming and suspends Flight Commander's normal DroneCAN node. It exits only when the flight controller reboots. Keep the powered CAN hub connected throughout any node firmware update.

    Holybro / AP_Periph two-node moving-baseline setup

    Select two fixed DroneCAN node IDs. Flight Commander configures the first F9P as the moving base (GPS_TYPE=17), the second as the moving rover (GPS_TYPE=18), enables GPS auto-configuration, saves both nodes, restarts them, and verifies the role readback. The rover must publish ardupilot.gnss.RelPosHeading before its yaw can enter heading fusion.

    Do not enable termination on both modules unless they are the two physical ends of the CAN trunk. A CAN hub or other device may already provide the required end termination.
