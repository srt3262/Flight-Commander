Flight Commander RTK routing

For a UART RTK receiver, select GPS / RTK GPS (UART) on the receiver UART and MAVLink / RTK corrections on the telemetry-radio UART. Flight Commander routes incoming RTCM3 corrections without blocking the flight loop. A DroneCAN RTK receiver is configured independently below. Both GPS links remain active, either receiver can be selected as the navigation primary, and RTCM corrections are forwarded to both enabled receivers.

Every CAN node must use the same bitrate. Node ID and bitrate changes take effect after the controller reboots. Install 120 Ω termination at each physical end of the CAN bus unless the connected hardware explicitly provides it. Primary selection changes which solution feeds navigation; it does not stop the other receiver. GPS and battery roles can be disabled, selected automatically, or bound to a fixed discovered node. Compass and relative-heading services are reported separately so a combined GPS/compass node can own both roles. Both GPS links retain independent RTK status for dual-GNSS moving-baseline yaw use.
