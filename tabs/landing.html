Unified configuration, mission planning, and ground control

Configure and fly from one application

Configure Flight Commander aircraft through the wired MSP connection, then use MAVLink telemetry for airborne ground control. Monitor live telemetry, send supported commands, and plan missions without changing applications. Official INAV remains available as an explicitly identified compatibility mode.

Mission and mapping tools

Build waypoint missions, generate survey grids from polygons, apply terrain-following altitudes, and transfer active missions over MAVLink. Wired MSP remains available for persistent mission storage and configuration.

Flight Commander 4.1.0

Flight Commander 4.1.0 removes the MAVLink startup-order dependency. Ground Control now keeps listening and automatically refreshes only the selected radio COM port until a valid aircraft heartbeat arrives.

The independent USB RTK base connection remains open during radio recovery, so survey-in can begin with the aircraft powered off and the aircraft link can be added later without restarting the survey.

INAV barometer/INS altitude from VFR_HUD is shown as relative altitude, while valid GPS altitude remains the MSL source. Live GCS diagnostics and the 4.0.8 compass, IMU and ground-speed fixes remain.

This is a Configurator-only beta. It reuses the verified Flight Commander Firmware 4.0.8 image and exact 4.0.8 firmware source; no flight-controller reflash is required when upgrading from 4.0.8.
