Unified configuration, mission planning, and ground control

Configure and fly from one application

Configure Flight Commander aircraft through the wired MSP connection, then use MAVLink telemetry for airborne ground control. Monitor live telemetry, send supported commands, and plan missions without changing applications. Official INAV remains available as an explicitly identified compatibility mode.

Mission and mapping tools

Build waypoint missions, generate survey grids from polygons, apply terrain-following altitudes, and transfer active missions over MAVLink. Wired MSP remains available for persistent mission storage and configuration.

Flight Commander 4.0.5

Flight Commander 4.0.5 Beta ships coordinated Configurator and firmware builds with matching downloadable source. Its MICOAIR743 firmware is built from the official INAV 9.1.0 target while retaining reviewed Flight Commander extensions for fresh IST8310 sampling, validated compass calibration, and the MICOAIR743 board transform. Physical testing established the canonical onboard mapping as X=-nativeY, Y=-nativeX, Z=nativeZ with user alignment CW 0 degrees. Firmware 4.0.5 keeps the accepted MICOAIR743 IST8310 transform and the 4.0.4 time-based sensor recovery, then separates sample freshness, heading availability, displayed field quality and fusion authority. A fresh stationary magnetic heading remains usable at displayed quality 0 with only a one-percent authority floor, and four stable samples initialize yaw through a dedicated startup state that is not blocked by the legacy GPS-heading flag. Disabled heading sources now reset, migrate and save with weight 0. The online flasher offers 4.0.5 and later only, removing the previously failed firmware revisions from its selectable list while local-file loading remains content- and target-validated. Flight Commander adds weighted heading fusion and UART/DroneCAN moving-baseline RTK yaw. The GPS and Alignment workflows retain per-source diagnostics and editable installation offsets; the fixed onboard chip-to-board transform remains target-owned and cannot be accidentally applied to external compass modules. The CLI, page help, settings help, OSD, tuning, and SITL surfaces now use Flight Commander's comprehensive first-party GitHub manual; all 246 graphical setting links are indexed there. SITL no longer presents inherited INAV product wording. Firmware Flasher keeps local firmware selection, online firmware download, and flashing as the three explicit actions. Firmware is never bundled inside the Configurator. Connected Flight Commander Firmware is identified through the versioned FCFW extension; fork-only features remain disabled unless the firmware explicitly advertises their capability. Official INAV retains compatible configuration and navigation-only mission tools; Ground Control commands and all Flight Commander-only features remain disabled. ArduPilot support has been removed.
