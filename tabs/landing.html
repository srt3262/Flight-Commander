Unified configuration, mission planning, and ground control

Configure and fly from one application

Configure Flight Commander aircraft through the wired MSP connection, then use MAVLink telemetry for airborne ground control. Monitor live telemetry, send supported commands, and plan missions through one Flight Commander Firmware-only application and release contract.

Mission and mapping tools

Build waypoint missions, generate survey grids from polygons, apply terrain-following altitudes, and transfer active missions over MAVLink. Wired MSP remains available for persistent mission storage and configuration.

Flight Commander 4.1.2

Flight Commander 4.1.2 makes Flight Commander Firmware the only supported controller firmware. The retired stock-firmware compatibility path and every reduced-functionality product mode have been removed.

Wired setup now requires the versioned FCFW identity before configuration tabs unlock. MAVLink remains in a detecting state until the Flight Commander signature and capability bitmap arrive, so a generic heartbeat can no longer be misidentified.

The Firmware Flasher now offers Flight Commander Firmware only and rejects any local or online HEX without the required FCFW identity or exact target match.

This Configurator-only release reuses verified Flight Commander Firmware 4.0.8 and its exact firmware source archive.
