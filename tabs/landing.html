Unified configuration, mission planning, and ground control

Configure and fly from one application

Configure Flight Commander aircraft through the wired MSP connection, then use MAVLink telemetry for airborne ground control. Monitor live telemetry, send supported commands, and plan missions without changing applications. Official INAV remains available as an explicitly identified compatibility mode.

Mission and mapping tools

Build waypoint missions, generate survey grids from polygons, apply terrain-following altitudes, and transfer active missions over MAVLink. Wired MSP remains available for persistent mission storage and configuration.

Flight Commander 3.0.2

Flight Commander 3.0.2 ships coordinated Configurator and firmware builds with matching downloadable source. Its MICOAIR743 firmware is built from the official INAV 9.1.0 target and preserves that release's target, compass, calibration, bus, and IMU behavior. Flight Commander adds its complete feature set around that baseline, including weighted heading fusion and UART/DroneCAN moving-baseline RTK yaw. The GPS and Alignment workflows retain per-source diagnostics and editable installation offsets without forcing a board-specific compass orientation. The CLI, page help, settings help, OSD, tuning, and SITL surfaces now use Flight Commander's comprehensive first-party GitHub manual; all 246 graphical setting links are indexed there. SITL no longer presents inherited INAV product wording. Firmware Flasher keeps local firmware selection, online firmware download, and flashing as the three explicit actions. Firmware is never bundled inside the Configurator. Connected Flight Commander Firmware is identified through the versioned FCFW extension; fork-only features remain disabled unless the firmware explicitly advertises their capability. Official INAV retains compatible configuration and navigation-only mission tools; Ground Control commands and all Flight Commander-only features remain disabled. ArduPilot support has been removed.
