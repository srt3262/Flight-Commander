Unified configuration, mission planning, and ground control

Configure and fly from one application

Configure Flight Commander aircraft through the wired MSP connection, then use MAVLink telemetry for airborne ground control. Monitor live telemetry, send supported commands, and plan missions without changing applications. Official INAV remains available as an explicitly identified compatibility mode.

Mission and mapping tools

Build waypoint missions, generate survey grids from polygons, apply terrain-following altitudes, and transfer active missions over MAVLink. Wired MSP remains available for persistent mission storage and configuration.

Flight Commander 4.0.8

Flight Commander 4.0.8 Beta lets you select each enabled and detected compass individually, learn its six-side orientation and alignment, then calibrate only that source's offsets and gains.

Onboard, external I2C/UART GPS-module and DroneCAN compasses retain independent persistent transforms, manual alignment and field calibration. A source cannot enter heading fusion until its own two calibration stages are valid.

Ground Control now uses ground speed as the only HUD speed indication. The verified 4.0.7 IMU handedness and compass baseline remain intact.

This build is a beta for propeller-off hardware acceptance. Successful testing will promote the same validated 4.0.8 artifacts to the official release without rebuilding different binaries.
