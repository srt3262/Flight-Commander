Unified configuration, mission planning, and ground control

Configure and fly from one application

Configure Flight Commander aircraft through the wired MSP connection, then use MAVLink telemetry for airborne ground control. Monitor live telemetry, send supported commands, and plan missions without changing applications. Official INAV remains available as an explicitly identified compatibility mode.

Mission and mapping tools

Build waypoint missions, generate survey grids from polygons, apply terrain-following altitudes, and transfer active missions over MAVLink. Wired MSP remains available for persistent mission storage and configuration.

Flight Commander 4.0.7

Flight Commander 4.0.7 Beta restores the MICOAIR743 IMU attitude path after the 4.0.6 roll-handedness regression. Raising the physical right side now remains a right-side-up roll throughout firmware and HUD telemetry instead of being mirrored.

The accelerometer and gyro once again use the verified 4.0.5 high-rate processing sequence. Compass-orientation learning derives its synchronized board-frame samples only when the 40 Hz compass task requests them, so learning no longer adds a second vector write inside either attitude update loop.

The persistent learned IST8310 transform, independent manual CW0 alignment, stationary heading availability and moving-baseline RTK features from 4.0.6 are retained. Recalibrate the accelerometer, then complete compass orientation and conventional compass calibration after flashing.

The managed flasher offers the verified 3.0.7 recovery baseline plus 4.0.7 and later. Failed 3.0.6-and-earlier, 3.0.8 and 4.0.0-through-4.0.6 firmware remain excluded from the managed list.
