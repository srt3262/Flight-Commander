Unified configuration, mission planning, and ground control

Configure and fly from one application

Configure INAV aircraft through the wired MSP connection, then use MAVLink telemetry for airborne ground control on INAV F7/H7, Pixhawk, and CubePilot-class flight controllers. Monitor live telemetry, send supported commands, and plan missions without changing applications.

Mission and mapping tools

Build waypoint missions, generate survey grids from polygons, apply terrain-following altitudes, and transfer active missions over MAVLink. Wired MSP remains available for persistent INAV mission storage and configuration.

Flight Commander 1.8.1

Built from the verified INAV Configurator 9.1.1 source base. INAV keeps its complete wired configurator and flasher, while ArduPilot controllers receive a metadata-driven setup GUI, verified first installation through STM32 DFU, and board-ID-checked APJ updates. This release makes the application dark-only with a complete contrast pass, replaces the ArduPilot setup surface with guided INAV-style controls backed by native parameters and full-parameter fallbacks, and makes first-connection INAV preset application bounded and verifiable. Version 1.8.1 restores readable dark-theme battery/control-profile fields and reliable motor-number overlays in both Mixer and Outputs. It also retains the guarded STM32 ROM-DFU and full-erase handoff when returning an ArduPilot controller to INAV, while retaining metric and imperial setup units and tuned INAV multirotor presets for 10, 12, 15, and 17-inch propellers.
