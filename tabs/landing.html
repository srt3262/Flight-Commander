Unified configuration, mission planning, and ground control

Configure and fly from one application

Configure Flight Commander aircraft through the wired MSP connection, then use MAVLink telemetry for airborne ground control. Monitor live telemetry, send supported commands, and plan missions without changing applications. Official INAV remains available as an explicitly identified compatibility mode.

Mission and mapping tools

Build waypoint missions, generate survey grids from polygons, apply terrain-following altitudes, and transfer active missions over MAVLink. Wired MSP remains available for persistent mission storage and configuration.

Flight Commander 2.0.5

Flight Commander 2.0.5 adds an explicit u-blox F9P/F9-series UART RTK rover preset and separate Alignment Tool targets for UART RTK, DroneCAN RTK, and moving-baseline modules. Calibration now detects and persistently corrects the MICOAIR743 onboard IST8310 rotation before calibration, preventing a fixed axis error from being mistaken for calibration drift. Ground Control places Relative Altitude beside Altitude (MSL) and removes the Air Speed tile. The CLI, page help, settings help, OSD, tuning, and SITL surfaces now use Flight Commander's comprehensive first-party GitHub manual; all 246 graphical setting links are indexed there. SITL no longer presents inherited INAV product wording. Firmware Flasher keeps local selection, online download, flashing, and offline recovery as distinct actions. Connected Flight Commander Firmware is identified through the versioned FCFW extension; fork-only features remain disabled unless the firmware explicitly advertises their capability. Official INAV retains compatible configuration and navigation-only mission tools; Ground Control commands and all Flight Commander-only features remain disabled. ArduPilot support has been removed.
