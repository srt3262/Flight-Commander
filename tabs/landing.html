Unified configuration, mission planning, and ground control

Configure and fly from one application

Configure INAV aircraft through the wired MSP connection, then use MAVLink telemetry for airborne ground control on INAV F7/H7, Pixhawk, and CubePilot-class flight controllers. Monitor live telemetry, send supported commands, and plan missions without changing applications.

Mission and mapping tools

Build waypoint missions, generate survey grids from polygons, apply terrain-following altitudes, and transfer active missions over MAVLink. Wired MSP remains available for persistent INAV mission storage and configuration.

Flight Commander 1.9.1

Built from the verified INAV Configurator 9.1.1 source base. INAV keeps its complete wired configurator and flasher, while ArduPilot controllers receive a metadata-driven setup GUI, verified first installation through STM32 DFU, and board-ID-checked APJ updates. This release keeps the application dark-only and makes ArduPilot use Flight Commander's own INAV tab layouts, labels, controls, and workflows. All 450 cataloged front-end functions resolve through direct, composite, equivalent, or command-backed ArduPilot translations, while All Parameters remains available for advanced native access. Version 1.9.1 also restores mirrored ArduPilot tab initialization, prevents a page error from locking every tab, rejects invalid pre-GPS map positions, adds MAVLink-backed calibration, sensor, motor, logging, Lua, console, and Search workflows, repairs INAV 9.1 preset compatibility, and verifies Quad X/Plus M1-M4 numbering and Props-in/Props-out rotation. It retains the guarded STM32 ROM-DFU/full-erase handoff, metric and imperial units, and tuned INAV Quad X starting points for 3, 5, 7, 10, 12, 15, and 17-inch propellers.
