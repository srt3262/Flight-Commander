# Flight Commander 4.0.8 hardware-test bundle

This retained beta input is intended for propeller-off hardware acceptance before any official 4.0.8 promotion.

The downloadable test bundle contains exactly:

1. `FC-Windows-v4.0.8.zip`
2. `FC-Configurator-Source-v4.0.8.zip`
3. `FC-Firmware-v4.0.8-MICOAIR743.hex`
4. `FC-Firmware-Source-v4.0.8.zip`

Remove all propellers before flashing or calibrating. Verify the onboard and external compass selections independently, complete the selected source's six-side learned orientation, then complete only that source's offset/gain calibration. Reboot and confirm the stored result for one compass is unchanged after calibrating the other.
