# Flight Commander 4.0.8 Ground Control diagnostics test build

This Configurator-only test build keeps the global diagnostics log available while Ground Control is active and adds transport-stage diagnostics that distinguish:

- inbound serial bytes,
- successfully decoded MAVLink frames,
- vehicle heartbeat timeout, and
- heartbeat restoration after a temporary outage.

No flight-controller firmware behavior is changed. The existing verified Flight Commander Firmware 4.0.8 remains the matching firmware for this diagnostic Configurator build.
