# Flight Commander 4.0.2 Beta

This coordinated beta contains Flight Commander Configurator 4.0.2 and MICOAIR743 firmware 4.0.2 for propeller-off bench validation.

## Compass persistence repair

- Keeps the bench-verified onboard IST8310 transform: `X = -nativeY`, `Y = -nativeX`, `Z = nativeZ`.
- Makes `CW0_DEG` the fixed MICOAIR743 onboard-compass alignment on every startup.
- Prevents generic configuration validation from silently replacing that target alignment.
- Resets incompatible legacy compass state with the new compass configuration schema.
- Applies calibration offsets and gains only when their hidden transform revision and signature match the current target, sensor, alignment and calibration values.
- Requires any future onboard transform change to advance the transform revision, preventing old calibration data from being reused with a changed coordinate system.

## Local firmware loading repair

- A locally stored Flight Commander HEX file no longer has to use a release-style filename.
- Renamed, older and newer local files are validated by Intel HEX structure and embedded firmware identity instead of filename alone.
- Embedded target identity is checked when available.
- Older files without an embedded target string can be loaded after explicitly selecting the supported `MICOAIR743` target.
- Online firmware downloads remain protected by release metadata, byte count, SHA-256 and target checks.

## Included components

The complete `Flight-Commander-v4.0.2.zip` contains exactly four coordinated files:

1. `FC-Windows-v4.0.2.zip`
2. `FC-Configurator-Source-v4.0.2.zip`
3. `FC-Firmware-v4.0.2-MICOAIR743.hex`
4. `FC-Firmware-Source-v4.0.2.zip`

This is a beta release. Perform the initial compass, calibration and firmware-flashing checks with propellers removed.
