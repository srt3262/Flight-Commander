# Flight Commander 4.0.6 Beta

This coordinated beta contains Flight Commander Configurator 4.0.6 and
MICOAIR743 firmware 4.0.6 with the four standard release deliverables.

## Learned onboard-compass orientation

- The IST8310 driver now publishes one canonical chip coordinate system instead
  of applying a target-specific fixed transform.
- The Calibration tab requires the normal six-position accelerometer calibration
  before orientation learning can begin.
- Six guided compass positions collect synchronized calibrated acceleration,
  board-frame gyro rate and canonical magnetometer samples while the controller
  is rotated around each upward-facing axis.
- Firmware scores all 24 physically valid right-handed signed-axis mappings and
  rejects insufficient range, ambiguous winners and excessive residual error.
- A successful result stores the mapping, confidence, residual, sensor
  fingerprint and calibration generation in persistent flight-controller
  configuration. It is loaded on every boot and is never relearned automatically.
- Manual compass alignment remains a separate installation adjustment and
  defaults to zero degrees. It cannot replace or overwrite the learned transform.

## Two-stage calibration and heading eligibility

Changing or clearing the learned transform invalidates the previous magnetic
zero/gain calibration. After orientation learning succeeds, run the conventional
compass rotation calibration. The onboard compass is excluded from heading fusion
until both the learned orientation and field calibration are valid.

## Managed firmware catalog

The online Flight Commander firmware catalog presents only the physically
verified 3.0.7 recovery baseline and firmware 4.0.6 or later. Failed revisions
3.0.6 and earlier, 3.0.8, and 4.0.0 through 4.0.5 are not selectable in the
managed flasher. Historical GitHub releases remain available for auditability;
local firmware loading remains based on embedded identity and hardware target,
not filename.

## Propeller-off validation

1. Flash 4.0.6 with propellers removed and perform a full chip erase only when
   intentionally resetting all saved configuration.
2. Complete and save accelerometer calibration.
3. Start Learn Compass Orientation and complete all six requested faces, rotating
   around the upward face until each card reaches 100%.
4. Confirm a proper mapping, confidence and residual are shown as stored.
5. Run the conventional compass field calibration.
6. Reboot and confirm the stored mapping remains valid without repeating either
   calibration.
7. Check clockwise yaw, north crossing, full 360-degree return and moderate
   pitch/roll stability before any controlled flight testing.
