# Flight Commander 4.1.3

Flight Commander 4.1.3 is a Configurator-only maintenance release. It
retains the bench-accepted Flight Commander Firmware 4.0.8 image and exact
firmware-source archive unchanged.

## Corrected behavior

- Ground Control now recognizes legacy Flight Commander Firmware 4.0.8 over
  MAVLink from the unique Flight Commander controller profile previously
  captured over the wired MSP setup link. The signed MAVLink `FCFW` identity
  remains authoritative whenever firmware advertises it.
- The online Firmware Flasher list contains only official and beta firmware
  assets published in this repository's GitHub Releases. Repeated copies of
  the same target/version are collapsed, with the official canonical firmware
  release preferred over beta or Configurator-wrapper copies.
- A local Intel HEX is now an explicit operator-controlled source. After the
  HEX parser accepts its syntax, Flight Commander does not reject it by
  filename, firmware family, embedded identity, version, or target. The
  operator is responsible for selecting a file appropriate for the hardware.
- The Welcome page now describes Flight Commander features and workflows
  instead of narrating the retirement of another firmware product path.
