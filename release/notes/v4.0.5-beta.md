# Flight Commander 4.0.5 Beta

This coordinated beta contains Flight Commander Configurator 4.0.5 and
MICOAIR743 firmware 4.0.5 with the four standard release deliverables.

## Startup heading and stationary fusion

- Retains the accepted onboard IST8310 transform:
  `X = -nativeY`, `Y = -nativeX`, `Z = nativeZ`.
- Retains the 4.0.4 time-based conversion timeout, atomic DRDY/XYZ read and
  nonblocking sensor reset/reconfiguration.
- Separates sample freshness, heading availability, displayed magnetic-field
  quality and fusion authority.
- Keeps a fresh finite magnetic heading available even when the displayed field
  quality is 0%. A one-percent authority floor keeps a single-source fused
  heading defined without hiding the warning or outweighing a healthier source.
- Requires four fresh fused samples that agree within 5 degrees before seeding
  disarmed startup yaw.
- Uses a dedicated Flight Commander startup-initialized state, so INAV's normal
  compass path can no longer set `gpsHeadingInitialized` first and permanently
  block the correct fused-heading seed.
- Startup no longer requires moving the controller before reported yaw catches
  the stationary source heading.

## Heading-source defaults

- Every disabled heading source resets and migrates to weight 0 in firmware.
- MSP configuration writes normalize disabled source weights to 0.
- The Configurator displays and saves disabled weights as 0, and restores the
  suggested enabled weight when the source is turned on.

## Flasher catalog cleanup

The online Flight Commander firmware catalog now requires version 4.0.5 or
later. Previously released 4.0.0 through 4.0.4 firmware is no longer selectable
in the flasher. Historical GitHub releases remain available for auditability;
local firmware loading remains based on embedded identity and hardware target,
not filename.

## Bench validation

1. Flash 4.0.5 with propellers removed.
2. Reboot while pointed away from north and leave the controller motionless.
3. Confirm source heading and reported heading agree after the short four-sample
   startup window without moving the controller.
4. Confirm a current sample with quality 0% is reported as fresh and low quality,
   not stale, and remains the fused source when it is the only enabled source.
5. Rotate through north, east, south and west and repeat with moderate roll and
   pitch before any controlled flight test.
