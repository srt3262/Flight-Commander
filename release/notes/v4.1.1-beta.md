# Flight Commander 4.1.1 Release

Flight Commander 4.1.1 is a Configurator-only Ground Control telemetry-state correction.

## Ground Control telemetry handoff

- Fixes the case where the serial log decoded a valid aircraft heartbeat and identified the vehicle while the Ground Control tab remained in its offline setup state.
- Ground Control now installs its MAVLink state subscription as soon as the selected serial transport opens, before the first aircraft heartbeat arrives.
- The first validated heartbeat immediately promotes the existing tab to live telemetry, refreshes the HUD and telemetry tiles, and starts the supported mission and command-readiness checks.
- No tab change, application restart, or manual reconnect is required for the waiting-to-live transition.

## Retained 4.1.0 behavior

- Automatic recovery continues to cycle only the selected vehicle-radio COM port when the bridge starts without a vehicle heartbeat.
- Independent USB RTK base survey-in and NTRIP sessions remain open during vehicle-link recovery.
- INAV relative-altitude and valid GPS MSL-altitude handling remain unchanged.
- Live MAVLink byte, frame, heartbeat-timeout, and heartbeat-restoration diagnostics remain available.

## Firmware

This release reuses the verified **Flight Commander Firmware 4.0.8** MICOAIR743 image and its exact published source archive. The firmware did not change, so aircraft already running Firmware 4.0.8 do not need to be reflashed.

Use propellers-off bench testing for the first Ground Control connection check.
